# 天地福音堂｜崇拜部 Portal

這是一個可部署到 GitHub Pages 的純靜態網站。第一版只做前端介面，使用假資料，不需要真實登入，也不連接 Google API。

## 技術限制

- 只使用 HTML、CSS、原生 JavaScript
- 不使用 React、Node.js、npm、資料庫或後端伺服器
- 可直接用 GitHub Pages 發布

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站骨架：標題、導覽、各個區塊的位置 |
| `styles.css` | 外觀樣式：顏色、字型、卡片、表格、手機版面 |
| `app.js` | 假資料與頁面邏輯：把日期、人名、更表填進網頁 |
| `README.md` | 專案說明與本機預覽、部署步驟 |

想改「下一次崇拜」、更表或待辦事項，請打開 `app.js`，修改最上方的 `data` 物件即可。

## 本機預覽

因為這是純靜態網站，不需要安裝任何套件。

### 方法一：直接開啟檔案（最簡單）

1. 在資料夾中找到 `index.html`
2. 雙擊它，或在瀏覽器選擇「開啟檔案」
3. 網站就會顯示出來

### 方法二：用 VS Code / Cursor 預覽

1. 用編輯器打開這個資料夾
2. 右鍵 `index.html`
3. 選擇用瀏覽器開啟

如果之後要接 Google 表單或簡報連結，請到 `app.js` 的 `data.links` 把 `"#"` 換成真實網址。

## 部署到 GitHub Pages

1. 把這四個檔案放到 GitHub 儲存庫的根目錄
2. 進入儲存庫的 **Settings → Pages**
3. Source 選擇 **Deploy from a branch**
4. Branch 選 `main`，資料夾選 `/ (root)`
5. 儲存後稍等一分鐘，網站網址會是：

`https://你的帳號.github.io/儲存庫名稱/`

## 第一版功能

- 頂部導覽：首頁、更表、崇拜預備、家事、文件庫、管理員
- 下一次崇拜資訊卡
- 常用功能按鈕（目前為佔位連結，日後可改成 Google Form／簡報）
- 提交歌單初稿、提交家事（之後都會用 Google Form）
- 本月崇拜更表
- 近日待辦事項
- 適合手機、平板、電腦的版面
